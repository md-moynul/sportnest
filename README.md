# 🏟️ SportNest

**SportNest** is a modern sports equipment and gear e-commerce platform built with Next.js. It provides a seamless shopping experience for sports enthusiasts — featuring product browsing, user authentication, cart management, and a full-featured backend API.

## ✨ Features

- 🛍️ **Product Browsing** — Explore a wide range of sports equipment and gear
- 🔐 **Authentication** — Secure sign-up and login powered by Better Auth
- 🛒 **Cart Management** — Add, update, and remove items from your cart
- 📦 **Order System** — Place and manage orders through the backend API
- 🔔 **Toast Notifications** — Real-time feedback via React Toastify
- 🎨 **Modern UI** — Clean, responsive interface built with HeroUI and Tailwind CSS
- 🌟 **Icon Support** — Rich iconography via Lucide React, React Icons, and Gravity UI Icons
- 🗄️ **MongoDB Integration** — Persistent data storage with MongoDB
- ⚡ **Server-Side Rendering** — Fast, SEO-friendly pages via Next.js 16

## 🏗️ Tech Stack

- **Frontend:** Next.js 16, React 19, Tailwind CSS v4, HeroUI
- **Backend:** Node.js, Express (via sportnest-server)
- **Database:** MongoDB
- **Auth:** Better Auth with MongoDB Adapter
- **Deployment:** Vercel
